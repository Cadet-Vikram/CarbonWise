# CarbonWise 🌱
**1M1B AI for Sustainability Internship Project**

**CarbonWise** is an AI-powered personal carbon footprint estimator. It helps users understand the environmental impact of their daily lifestyle choices (transport, diet, energy) and provides personalized, actionable advice using **AI**.

![Project Screenshot](https://via.placeholder.com/800x400?text=CarbonWise+Screnshot+Placehoder)

## 🌍 SDG Alignment
**SDG 13: Climate Action**
*   Target 13.3: Improve education, awareness-raising and human and institutional capacity on climate change mitigation.

## 🚀 Features
*   **Smart Calculator**: Estimates daily CO₂e emissions based on transport, diet, and energy usage.
*   **AI Insights**: Uses **Groq API (Llama 3)** to generate specific, non-generic tips based on the user's highest emission category.
*   **Visual Feedback**: Interactive score circle and "Glassmorphism" UI for an engaging user experience.
*   **Responsiveness**: Works seamlessly on mobile and desktop.

## 🛠️ Tech Stack
*   **Frontend**: HTML5, CSS3 (Modern/Glassmorphism), JavaScript (ES6+).
*   **AI Integration**: Groq API (Model: `llama-3.3-70b-versatile`).
*   **Tools**: Git, GitHub Pages.

## ⚙️ Setup & Usage
1.  Clone the repository:
    ```bash
    git clone https://github.com/YOUR_USERNAME/CarbonWise.git
    ```
2.  Open `index.html` in your browser.
3.  **Note**: The API Key is currently embedded for demonstration purposes. In a production environment, this would be secured on a backend server.

## 🤖 Responsible AI
This project uses AI to *inform* and *assist*, not to judge.
*   **Transparency**: Users are clearly told that tips are AI-generated.
*   **Privacy**: No personal data is stored or sent to a database; everything runs in the browser session.
*   **Fairness**: The model is prompted to be "friendly" and "encouraging," avoiding shaming language.
